# FinFlow

FinFlow — адаптивный личный финансовый помощник. В нём можно вести доходы и расходы, управлять счетами и переводами, отслеживать подписки и долги, задавать бюджеты и цели, смотреть аналитику и прогноз расходов.

## Возможности

- Операции с поиском, фильтрами и пользовательскими категориями.
- Несколько счетов с начальным балансом; переводы между своими счетами меняют остатки счетов, но не считаются доходом или расходом.
- Финансовые цели и подушка безопасности с взносами и прогрессом. Целевые суммы распределяются внутри текущего баланса и не перемещают реальные деньги между счетами.
- Повторяющиеся доходы и расходы. Просроченные повторы создаются при следующем открытии приложения; расписание можно поставить на паузу или удалить в профиле.
- Ежемесячные бюджеты по категориям, аналитика и прогноз темпа расходов.
- Аналитика сравнивает расходы с прошлым месяцем, показывает динамику доходов и расходов за шесть месяцев и оценивает баланс после ближайших подписок.
- Прогноз до указанного дня зарплаты с учётом ближайших подписок и отложенных на цели сумм.
- Подписки с датами списания и напоминаниями.
- Учёт долгов и отметка погашения.
- Настраиваемый формат валюты (RUB, USD, EUR, PLN) и цвет акцента. Смена валюты меняет только отображение: пересчёта по курсу нет.
- Скрытие сумм на экране и PIN-блокировка приложения.
- JSON резервные копии и CSV экспорт операций.
- PWA: приложение можно установить, а его локальная оболочка доступна офлайн после первого открытия.

## Данные и приватность

Операции и настройки хранятся в `localStorage` этого браузера. Сервер и синхронизация между устройствами не используются. Чтобы перенести данные, скачайте JSON резервную копию в настройках и импортируйте её на другом устройстве. PIN хранится в виде производного хеша и не включается в экспорт; блокировка PIN не шифрует данные `localStorage`.

## Запуск локально

Нужен Node.js 18 или новее.

```sh
npm ci
npm run check
npm run preview
```

Откройте адрес, который напечатает `npm run preview` (по умолчанию `http://127.0.0.1:4173`).

`npm run check` собирает Tailwind CSS, проверяет JavaScript и запускает тесты. Файл `tailwind.generated.css` включён в репозиторий, поэтому статический сайт можно развернуть без сборочного шага.

GitHub Actions запускает те же проверки для каждого push и pull request.

## Развёртывание

Можно публиковать корень репозитория как статический сайт, например через GitHub Pages. После изменения разметки или классов Tailwind обновите CSS командой `npm run build:css` и включите обновлённый `tailwind.generated.css` в коммит.
